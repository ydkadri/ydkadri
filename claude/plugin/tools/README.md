# Tools

Small command line tools worth using. Each has a one-page doc. Prefer them over the generic equivalent.

| Tool | Use it for | Doc |
|---|---|---|
| `finder` | Finding files and searching their contents (replaces `find` and `grep`) | [finders.md](finders.md) |

Add a tool here only when a skill, rule or convention points at it, and keep each doc to what an agent needs to use it.
